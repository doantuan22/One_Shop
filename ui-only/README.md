# OneShop UI

Thư mục này chỉ chứa tài nguyên giao diện được sao chép từ `src/main/resources`:

- `templates/`: các trang và layout Thymeleaf cho khách hàng, nhân viên và quản trị viên.
- `static/`: CSS, JavaScript, ảnh, font và thư viện giao diện.

Các template vẫn dùng cú pháp Thymeleaf và cần dữ liệu từ ứng dụng backend để hiển thị đầy đủ. Đây là bản sao; mã nguồn gốc không bị thay đổi.
